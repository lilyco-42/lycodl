# lycodl 浏览器扩展（最小版）

把当前页面或页面上任意链接，一键发送到本机正在运行的 **lycodl** 下载器。

- 只连 `127.0.0.1` / `localhost`（端口 8765–8785 自动发现），不向任何外部服务器发送数据。
- 使用 MV3，请求全部在 background service worker 里发出（Origin 是 `chrome-extension://<id>`，后端据此放行）。
- 本版**没有 content script**：不注入任何脚本到网页，只用右键菜单 / 弹窗 / 快捷键。

## 一、加载扩展

1. 打开 Chrome（或 Edge / Brave 等 Chromium 系浏览器）地址栏输入 `chrome://extensions`。
2. 打开右上角的 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择本仓库的 `extension/` 目录（包含 `manifest.json` 的那一层）。
4. 记下扩展的 ID（形如 `abcdefghijklmnop...`），不需要手动配置端口，插件会自己找。

## 二、复制令牌并粘贴

1. 先启动 lycodl，打开它的网页（形如 `http://127.0.0.1:8766`）。
2. 进入 **设置** 页签，找到 **浏览器扩展** 一节，点 **复制插件令牌**。
3. 点浏览器工具栏的 lycodl 图标打开弹窗，把令牌粘到 **插件令牌** 输入框（点「显示」可以核对内容）。
4. 端口留空即可（自动发现 8765–8785；如果你知道确切的端口也可以手填）。
5. 下载模式选 **视频** 或 **音频**。
6. 点 **测试连接**，状态区会显示 `连接成功：lycodl <版本> @ 端口 <端口>`（顺带显示 yt-dlp 版本）。
7. 点 **保存设置**（测试连接也会顺便保存一次）。

## 三、日常用法

- **当前页面**：在视频页点工具栏的 lycodl 图标，弹窗里点 **发送当前页面**；或者直接按 `Alt+Shift+L`。
- **页面上某个链接 / video / audio 元素**：右键 → **发送到 lycodl**。
- 发送时先解析（可能十几秒，会先弹「正在解析…」通知并给图标挂上 `…` 角标），成功入队后弹「已加入下载队列」通知并短暂显示 `OK` 角标；失败会弹通知显示后端返回的原始错误。
- 入队之后到 lycodl 网页的 **任务** 页签看进度；下载完成的文件在 **文件** 页签里。

## 四、注意

- **只连本机**：请求目标是 `http://127.0.0.1:<port>`，令牌只存在浏览器本地 `chrome.storage.local`，不会发给外部服务。
- **令牌可重新生成**：在 lycodl 网页「设置 → 浏览器扩展」里点 **重新生成令牌**，旧的立即失效，需要回到扩展弹窗重新粘贴并测试连接。
- **端口自动发现**：lycodl 默认监听 8765，被占用会自动顺延（最多 20 个端口），插件会在 8765–8785 之间逐个探测 `GET /api/health` 并记住命中的端口。换了端口后如果连不上，把弹窗里的端口清空再点「保存设置」即可重新发现。
- **403 / 401 排查**：
  - `401` → 令牌不对或已轮换，重新复制粘贴。
  - `403` → 请求不是从扩展 background 发出的（例如被其他扩展转发）；正常使用本扩展不会出现。
  - 弹「无法连接 lycodl」→ 程序没启动，或端口不在 8765–8785 区间。
- 扩展图标是自动生成的内联 SVG/PNG 占位图（紫底白色下箭头），想换的话替换 `icons/` 下的四个 PNG 即可。

## 五、文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | MV3 清单：权限、右键菜单、background worker、popup、快捷键 |
| `background.js` | 端口发现、右键菜单、两段式发送（probe → download）、通知与角标 |
| `popup.html` / `popup.js` | 弹窗界面：令牌 / 端口 / 模式、保存、测试连接、发送当前页面 |
| `icons/` | 16 / 32 / 48 / 128 图标 |
